# Al Amal Digital Agency 🚀

> Awwwards-inspired multi-page digital agency website with Three.js WebGL, GSAP animations & real Unsplash images.

## ✨ Features

- 🌐 **8 Full Pages** — Home, Services, Portfolio, About, Pricing, Blog, Blog Post, Contact
- 🎨 **Three.js WebGL Scene** — Torus knot + 1,600 particles + floating geometries
- ⚡ **GSAP + ScrollTrigger** — Scroll animations, stagger effects
- 🖱️ **Magnetic Cursor** — Dual cursor with blend-mode difference
- 🏷️ **3D Card Tilt** — Mouse-tracking tilt on all cards
- 📱 **Fully Responsive** — Mobile-friendly
- 🇸🇦 **Arabic RTL Support** — One-click language toggle

## 🚀 Quick Start

git clone https://github.com/lizaanwar-blip/Al-Amal-Agency-.git
